# VPN connection troubleshooting

In this demonstration environment, check that the internet connection works before attempting VPN access. Close the VPN client completely, reopen it, and sign in again using the expected test account. If you receive an authentication prompt, approve only the prompt that you initiated.

If the VPN reports that access has not been granted, this might be a new VPN access request rather than a connectivity incident. If an existing approved VPN connection has stopped working, use the VPN Connection Failure incident offering.

No real VPN service is available through this prototype.
