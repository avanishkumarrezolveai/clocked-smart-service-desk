# Laptop does not power on

This document is for a fictional test environment.

1. Verify the power adaptor is firmly connected to the laptop and wall outlet.
2. Try a different working outlet if available.
3. Disconnect external accessories, including docking stations and USB devices.
4. Hold the power button for 15 seconds, then try starting the laptop once.
5. If the device remains unresponsive, stop troubleshooting and request Hardware Support.

When escalating, provide the issue description and the affected device if known. It is not necessary to know the serial number before asking for help.
